# ADM (Autism Document Management)

Межведомственная цифровая платформа для управления документами и маршрутизацией при расстройствах аутистического спектра (РАС).

## Проблема
Родители детей с РАС сталкиваются с бюрократическим тупиком из-за разобщенности трех ведомств (МЗ, МП, МТСЗН). На сбор и переоформление стандартных справок (027/у, ВКК) уходит от 6 до 12 месяцев, из-за чего семья упускает критически важное «окно раннего вмешательства» (1,5–4 года). В Казахстане на учете состоит более 15 000 детей с РАС.

---

## Решение
ADM автоматизирует и упрощает бюрократический процесс с помощью ИИ:
- **Интервью:** Родитель проходит адаптивное интерактивное интервью на русском или казахском языке.
- **Движок правил (R01–R15):** На основе ответов формируется персональный межведомственный кейс-план.
- **Безопасность:** Перед отправкой данных в LLM персональные данные (имена, ИИН, телефоны) скрываются, а ответы проверяются на недопустимые формулировки (например, постановку диагнозов).
- **Верификация:** Построенный план проверяется профильным куратором перед отображением родителю.

## Архитектура и Структура проекта

* `apps/web` (Next.js) — пользовательский интерфейс на русском и казахском. Пошаговое интервью по разделам. Кабинет родителя (план, шаг с подсказкой, календарь, напоминания, документы) и кабинет куратора (семьи, проверка плана, просрочки). Поддерживает установку в качестве PWA-приложения на телефон с оффлайн-доступом к последнему плану.
* `apps/api` (FastAPI) — серверная логика и REST API:
  - Авторизация и роли.
  - Движок правил R01–R15 для построения плана.
  - Управление кейс-планами (версии и статусы).
  - Эскалация просрочек по уровням 0–3.
  - Работа с документами, уведомлениями и генерация PDF-отчётов.
* `data` + `apps/api/alembic` (SQLite / Supabase) — схема базы данных (миграции), справочник 15 госуслуг РК (ПМПК, ВКК, МСЭ, ИПР, выплаты и др.), 18 вопросов интервью, нормативные документы, типовые сценарии (Кейс А — первичный маршрут, Кейс Б — продление с инвалидностью).
* `apps/api/app/modules/llm` (ai_agent) — интеграция с OpenAI Structured Outputs для задач: выбор следующего вопроса, разбор свободного текста, простое объяснение шагов на ru/kk, распознавание загруженных документов.

## Статус реализации («Что готово»)

| Раздел | Что сделано |
| :--- | :--- |
| **Интервью** | 8–12 адаптивных вопросов в 6 разделах, кнопки «Назад», «Не знаю» для дат, подсказки «зачем спрашиваем» |
| **План** | Построение по правилам R01–R15, верификация куратором, межведомственный маршрут по 3 ведомствам со сроками |
| **Шаг** | Инструкции (что сделать, что взять, куда обратиться), кнопка «Я сделал», выгрузка памятки в PDF |
| **Календарь и напоминания** | Сроки по месяцам, экспорт в календарь телефона, блоки «Просрочено» и «Скоро срок» |
| **Документы** | Учет недостающих документов, загрузка PDF с распознаванием срока действия |
| **Куратор** | Проверка и правка плана, мониторинг просрочек с готовыми обращениями, PDF-выписка, демо-панель |
| **Эскалация** | Сдвиг сроков зависимых шагов, уровни 0–3, система уведомлений |
| **Доступ** | Регистрация родителя, вход, демо-вход одной кнопкой, раздел FAQ, ru/kk, светлая и тёмная тема |
| **Качество** | Успешно пройдено 179 автотестов |
